# 06‑38 — CEMS (Flue Gas / Emission)

> 13 mục §10. Đo phát thải liên tục (read‑only, báo cáo môi trường).

| # | Mục | Nội dung |
|---|---|---|
| 1 | Chức năng | Đo phát thải liên tục: **SO₂, NOx, bụi, CO, O₂, lưu lượng khói** |
| 2 | Nguyên lý | Analyzer tại ống khói (extractive/in‑situ); hiệu chỉnh tự động; xuất báo cáo tuân thủ |
| 3 | Thiết bị | Analyzer cabinet, sample probe/line, calibration gas, flow monitor |
| 4 | Instrument | SO₂, NOx, dust, CO, O₂, flue gas flow, temp |
| 5 | PLC/DCS | CEMS DAS (data acquisition) — **read‑only** vào IDTP |
| 6 | Interlock/Trip | Không điều khiển process; alarm vượt ngưỡng phát thải |
| 7 | Alarm | `CEMS-SO2-HH` P2 · `CEMS-NOX-HH` P2 · `CEMS-DUST-HH` P1 · analyzer fault P3 |
| 8 | Trend | SO₂, NOx, dust, CO, O₂, flow (báo cáo giờ/ngày) |
| 9 | Faceplate | Analyzer status + calibration |
| 10 | Tag | `CEMS_SO2_01` (mg/Nm³) · `CEMS_NOX_01` · `CEMS_DUST_01` · `CEMS_CO_01` · `CEMS_O2_01` (%) · `CEMS_FLUEFLOW_01` |
| 11 | Animation | Giá trị phát thải; trạng thái analyzer |
| 12 | Sequence | Auto calibration định kỳ; chuyển sang giá trị thay thế khi cal |
| 13 | SOP | Giám sát ngưỡng phát thải; hiệu chuẩn định kỳ; xuất báo cáo môi trường |

**Định mức:** SO₂ · NOx · bụi · CO · O₂ · lưu lượng khói.
